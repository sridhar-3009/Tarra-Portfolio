# Camera roll

Drop photos (.jpg, .jpeg, .png, .webp) into this folder and they show up in
"From my camera roll" on the home page — no code changes needed.

- Newest first: name files so they sort by date, e.g. `2026-11-21-arthurs-seat.jpg`.
- Optional caption: add an entry in `src/data/photos.js` keyed by file name.
- Keep each file under ~1 MB (export at ~1600px on the long edge).
